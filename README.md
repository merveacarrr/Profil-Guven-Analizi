# Profil Güven Analizatörü 🚀

Sosyal medya profillerinin güvenilirlik düzeylerini belirlemek için geliştirilen Python tabanlı bir uygulama. Proje, sosyal medya platformlarındaki sahte ve yanıltıcı hesapları tespit ederek güvenilir bir dijital ortam yaratmayı amaçlamaktadır.

---

## 📋 Proje Özeti
Bu proje, Selenium gibi otomasyon araçlarını kullanarak sosyal medya profillerinden veri toplamayı ve bu verileri makine öğrenimi algoritmalarıyla analiz etmeyi içerir.

### Temel Amaçlar:
- Kullanıcıların sosyal medya profillerinin güvenilirlik puanlarını hesaplamak.
- Sahte hesapları tespit ederek güvenilir çevrimiçi etkileşimleri artırmak.
- Veri madenciliği ve istatistiksel analizlerle metrik değerlendirmesi yapmak.

---

## 🛠️ Kullanılan Teknolojiler

| Teknoloji             | Açıklama                                                |
|-----------------------|--------------------------------------------------------|
| **Python**            | Veri işleme ve analiz için kullanılan ana programlama dili. |
| **Selenium**          | Web sayfalarından veri çekmek için kullanılan otomasyon aracı. |
| **Pandas & NumPy**    | Veri işleme ve temizleme işlemleri.                     |
| **Scikit-learn**      | Makine öğrenimi algoritmalarını uygulama.               |
| **Flask**             | Model sonuçlarını sunmak için kullanılan web framework. |
| **Matplotlib & Seaborn** | Veri görselleştirme kütüphaneleri.                  |

---

## 🚀 Proje Özellikleri

- **Selenium ile Veri Çekme**: Kullanıcı profillerinden takipçi sayısı, gönderi etkileşim oranları gibi metriklerin otomatik olarak toplanması.
- **Makine Öğrenimi Modelleri**: Naive Bayes, Yapay Sinir Ağları ve Karar Ağaçları gibi modeller kullanılarak güven puanı hesaplamaları.
- **Görselleştirme**: Sonuçların grafiklerle kullanıcıya sunulması.
- **Web Tabanlı Arayüz**: Flask framework kullanılarak kullanıcı dostu bir arayüz.

---

## 📊 Veri İşleme ve Analiz Aşamaları

### 1. **Veri Toplama**
- Selenium WebDriver kullanılarak sosyal medya profillerinden veri çekilir.
- Proxy sunucuları ile IP engellemeleri önlenir.

### 2. **Veri Temizleme ve Hazırlama**
- Pandas ve NumPy ile hatalı ve eksik veriler düzeltilir.
- Özellik mühendisliği ile veriler analiz için optimize edilir.

### 3. **Model Eğitimi**
- **Naive Bayes**: Hızlı ve etkili sınıflandırma için.
- **Yapay Sinir Ağları**: Daha karmaşık ve yüksek doğruluklu analizler için.
- **Karar Ağaçları**: Yorumlanabilir modeller için kullanılır.

### 4. **Görselleştirme**
- Matplotlib ve Seaborn ile anlamlı grafikler oluşturulur.
- Eğitim süreçleri ve sonuçları kullanıcıya görsel olarak sunulur.

## 🖥️ Kullanım Adımları

### 1. **Projeyi Klonlayın**
```bash
git clone https://github.com/kullaniciadi/profil-guven-analiz.git
cd profil-guven-analiz
```

### 2. **Gerekli Kütüphaneleri Yükleyin**

### 3. **Uygulamayı Çalıştırın**
```bash
python app.py
```
